# vkQuake-OpenXR

Quake with OpenXR stereoscopic rendering and head tracking, retaining mouse aiming and keyboard movement.

## Requirements

Windows x64, a Vulkan-capable graphics card, an OpenXR headset, and Quake game data.

## Install and launch

1. Extract all files into your Quake installation folder.
2. Start your headset's OpenXR software.
3. Run `vkQuake-OpenXR.exe`.

## Recenter

1. Sit in your playing position and look straight ahead.
2. Click **Mouse1** to recenter.
3. Click **Mouse1** to confirm, or **Mouse2** to retry.

To recenter later, enter `xr_recenter` in the Quake console.
